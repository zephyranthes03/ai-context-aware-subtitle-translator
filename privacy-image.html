Privacy Policy — AI Context-Aware Image Translator

Last updated: 2026-10-19

AI Context-Aware Image Translator reads and translates text in images you choose to process. The developer does not operate a translation server. The extension has no developer account, analytics, advertising trackers or automatic telemetry. Reading content is not automatically sent to the developer.

AI connections you configure

Configure a connection before translation. The extension supports local model servers and supported remote API endpoints. It does not include a hosted AI service or use the subscription helper available with the sibling text products.

  • Image recognition: source images, rendered PDF pages, image tiles or selected crops go to your configured recognition endpoint. Recognition or layout recovery can send additional crops from the same source. Images can contain sensitive information; choose the content and endpoint accordingly.
  • Translation and context: recognized source text, target language, relevant work information, names, terms, saved expressions and limited preceding original/translation pairs go to your configured translation endpoint. Recognition and translation can use different connections.
  • Quick explanations: the selected translation and, when available, its recognized original go to your configured quick-answer connection to request an explanation.
  • Connection setup: listing models, testing a connection or testing image support contacts the endpoint you selected. API credentials and configured authentication headers authenticate those requests.

AI responses are data, not downloaded executable code. If the selected model runs entirely on your computer without forwarding requests, AI payloads can stay on your computer. A localhost address alone does not establish how another program handles data. Remote providers receive the requested content under their own privacy policies and terms. Model billing is separate from the extension.

Source websites and selected-area capture

The extension reads image/page addresses and relevant page information to locate content you activate, associate translations with their source and prepare supported chapters. It may fetch images from their original URLs for recognition. Current- or next-chapter preparation can open source pages in background tabs using your browser session. Those websites receive normal browser requests independently of AI processing.

For selected-area translation, the extension may capture the visible tab after you activate the feature when direct image access is unavailable. The temporary capture is cropped before recognition; the selected crop is used for that reading. A blocked or blank capture is rejected. The extension does not obtain encryption keys or decrypt protected book files.

The extension does not use Chrome's browsing-history API or create an analytics profile of your browsing. Source URLs and selected work/chapter context are nevertheless processed and may be stored as described below.

Local storage and retention

Local browser extension storage holds:

  • connection settings, API credentials and headers, model choices, target language and display preferences;
  • per-work Series DB information, terms, expressions and local overrides;
  • bounded recognition and translation caches, source identifiers and processing/recovery records;
  • manually saved source corrections, translations and typography, with source-identity information to avoid applying an edit to the wrong content.

The prepared chapter translation cache also uses browser session storage and is limited to two chapters and 8 MiB. Session navigation and progress records, including chapter addresses, are stored separately and can retain information about more than two chapters during the browser session; that cache limit does not cover these separate records. Cached/prepared content can be evicted or need processing again. These caches are not a permanent archive of everything you read.

Normal recognition/translation caches and saved manual edits do not store the full source image. Active page/viewer/capture sessions can retain image pixels in memory while needed. Clearing ordinary caches preserves separately saved edits. Settings provides separate saved-edit export, import and deletion controls. Saved edits are size-limited; exceeding the limit is reported rather than silently deleting previous human edits.

Manage settings, caches and work data using the extension's controls. Removing the extension clears its browser storage. Original local files, exported files, provider accounts and data retained by a remote provider are separate and are not deleted by uninstalling the extension.

Exported files and support

Exporting reference data or saved edits creates a file under your control. An explicitly invoked diagnostic reading replay can also include the source page image, recognized text, translations and reading state. Other diagnostic exports may contain only state. Diagnostic files are not automatically uploaded; review them before sharing.

If you contact support or post an issue, the developer and hosting service receive the information you submit. Public issues are visible to others. Do not include API credentials or private reading content in a public report.

Permissions and choices

Active-tab access and scripting support user-activated image reading and overlays. Storage saves the local data above. Context menus open selected pages, links or images in the extension's viewer. An offscreen document can run packaged local image-processing workers to prepare source crops for recognition.

Localhost permissions allow connections to model servers on your computer. Optional HTTP/HTTPS host access is requested for relevant sites and configured API endpoints. Chrome presents the corresponding permission request. Review or revoke site access in Chrome; unavailable access may prevent translation or chapter preparation.

Limited use

User data is used and transferred only to provide the image-reading and translation features you request, and support you explicitly choose to contact. The developer does not sell user data, use it for advertising, or use or transfer it for creditworthiness or lending decisions. The extension's use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

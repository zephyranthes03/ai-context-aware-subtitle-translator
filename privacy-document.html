Privacy Policy — Context-Aware Document Translator

Last updated: 2026-09-08

The developer does not operate a translation server. Translation and reading data are not automatically sent to the developer. The extension has no developer account or sign-in and no analytics or telemetry. If you choose to submit a problem report, the developer receives that report as described below.

Everything it does happens either locally in your browser, or as a direct connection from your browser to a service you chose and configured.

What leaves your browser, and to where

1. The AI connection you configured

To translate, the extension sends the text of the page or the text you selected to the model connection you set up in Settings. That connection is one of:

  • a model running on your own machine (for example a local server on 127.0.0.1) — in this case the text never leaves your computer;
  • an API endpoint you supply a key for; or
  • an optional CLI bridge running on your own machine, which invokes a supported AI CLI and sends the request to that provider. Eligibility and billing depend on the CLI account and authentication settings. Current routes are Codex, Claude Code and Gemini CLI; Gemini CLI requires eligible Code Assist Standard/Enterprise access for its subscription route. Personal Google AI Pro/Ultra access through Gemini CLI has ended. Antigravity CLI and Grok Build are not integrated into this version.

The extension has no endpoint of its own and no fallback destination. If you have not configured a connection, no translation request is made at all.

Along with the text, a request may carry the page title and URL, target language, your question, and relevant context from the work's Series DB, including names, renderings and work details. API credentials authenticate requests only to their configured endpoint; a local bridge pairing token authenticates the helper.

2. The website you are already reading

Two features fetch a page from the site you are on, using your own browser session, exactly as opening the page yourself would:

  • Next-page pre-translation, when you enable it, fetches the following page so it is ready when you get there.
  • Fetch work details, which reads the work's own page for its title and description. This happens only when you pin your first rendering for a work, or when you press the button for it — never on opening a chapter, and once per work.

These requests go to that site and nowhere else.

3. An AI website, when you choose the handoff action

"Ask on AI site" opens or reuses the configured AI website and inserts your question and selected text, with any page context included by the configured prompt. This exposes that content to the website. The connection's submission setting determines whether the extension also submits it automatically or only prepares the input. Built-in ChatGPT and Claude connections default to automatic submission; a custom automatic form requires its configured submit selector. Choose prepare-only in Settings if you want to review the input before submitting.

4. A problem report, only when you submit one

The "Report a problem" link opens a pre-filled form. It carries the extension version, your target language, the kind of connection you use and its model name, and your interface language. The current page address and title are included only if you tick the box for them, which is off by default.

Opening the Google Form sends the pre-filled fields to Google in the URL query. The form lets you edit those fields before submitting the report, but editing them does not undo the URL data already sent to Google. The developer receives the completed report when you press Submit. Google's privacy policy applies to the form. You can open a report without including the source page information.

What is stored, and where

All of it is stored locally in your browser, using Chrome's extension storage:

  • your settings (connections, API keys/pairing tokens, target language, display preferences);
  • the renderings you pinned, per work and per target language;
  • recent prefetched page results in browser session storage: up to five pages, also subject to size limits and eviction. Available matching results can be reused; this is not permanent storage of every page you read.

These records are stored locally. Relevant content and credentials are used only in the disclosed requests above. Removing the extension clears its browser storage; saved/exported files and separate CLI accounts remain under your control. You can also manage individual works from the Series knowledge page.

Site access

You can use the extension on the active tab, enable it for selected sites, or explicitly grant all HTTP/HTTPS sites for the selection-tools setting. Chrome asks for the corresponding permission. Enabled-site content tools can load automatically. Next-page pre-translation can fetch an approved next page in the background when you enable that feature. Configured API and AI-website hosts also require the relevant access; localhost access is declared at installation.

Sensitive information

Because you choose the connection, you decide where your text goes. If you point the extension at a model running on your own machine, the text being translated does not leave that machine. If you point it at a third-party API or subscription, that provider's terms and privacy policy apply to what is sent.

Contact

Problems and questions: the "Report a problem" link in the extension, or the issue tracker at https://github.com/zephyranthes03/ai-context-aware-subtitle-translator/issues.

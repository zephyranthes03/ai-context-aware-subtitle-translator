AI Context-Aware Subtitle Translator

A Chrome extension that generates AI translations of streaming video subtitles, using full-scene context (character voice, relationships, glossary terms) for more natural, consistent translations than a line-by-line machine translation.

Free to install and use — bring the AI you already have: a local model (Ollama / LM Studio), your existing ChatGPT or Claude subscription, a free DeepL key, or your own API key. No sign-up, no in-extension payments.

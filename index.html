Context-Aware Translation

Two Chrome extensions that translate with the whole work in view, rather than a line at a time. Both are free, and both run on an AI connection you set up yourself — a local model (Ollama / LM Studio), a subscription you already pay for, or your own API key. No sign-up, no in-extension payments, and no server of ours in between.

AI Context-Aware Subtitle Translator

Generates AI subtitles for streaming video by re-translating the stream's own caption track, using full-scene context — character voice, relationships, glossary terms — for more natural and consistent results than a line-by-line machine translation.

  • Install from the Chrome Web Store
  • Privacy Policy

Context-Aware Document Translator

Translates whole pages and selected text. Long works invent their own vocabulary, so you can pin how a work writes a coined term once and have every later chapter use it — pinned words are held out of the request entirely, so they cannot come back changed. Those decisions are kept per work and per language and can be exported as a file to share with anyone reading the same thing. Serialized pages can be translated a page ahead, and a quick answer or a handoff to an AI website is a selection away.
